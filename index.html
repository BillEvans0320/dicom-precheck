DICOM 업로드 전 점검

영상은 이 PC 밖으로 전송되지 않습니다. 모든 처리는 브라우저 안에서 이루어지며, 원본 파일은 수정하지 않습니다.

1. 폴더 또는 ZIP 선택

DICOM 폴더나 ZIP 파일을 여기에 끌어다 놓거나

선택된 폴더 없음

ZIP 파일은 압축을 풀지 않고 그대로 넣으면 됩니다. ZIP 안의 폴더 구조가 결과에 그대로 유지됩니다. 암호가 걸린 ZIP과 ZIP 안에 다시 들어 있는 ZIP은 읽지 않습니다.

3. 후보 확인

영상에 글씨가 찍혀 있을 수 있는 파일(리포트·화면 캡처 등)을 글자 인식(OCR)으로 검사한 결과입니다. 썸네일을 보고 파일마다 업로드 여부를 정하세요.

  • 유력: 이름·Patient ID·생년월일 같은 항목이 보이는 파일입니다. 기본값은 제외입니다.
  • 확인 필요: Sex·Age·Physician·Operator 같은 항목이나 7자리 이상 숫자가 보이는 파일, 또는 글자 인식을 할 수 없었던 파일입니다. 기본값은 업로드이니 썸네일을 꼭 확인하세요.
  • JLK 분석 결과: JLK 프로그램이 만든 결과물입니다. 카드에 글자 인식 결과(OCR: 정상 / 확인 필요)가 함께 표시됩니다. 기본값은 업로드입니다. 이름·ID가 보이는 JLK 파일은 '유력'으로 분류됩니다.
  • 정상(장비 문구·각도·단위 등만 있는 파일)은 화면에 따로 표시하지 않고 위 요약에 개수만 보여 주며, 모두 업로드됩니다. 같은 시리즈의 대표 3장(첫·가운데·마지막)이 모두 정상이면 나머지 장도 같은 결과로 판정합니다. 파일별 판정은 보고서(CSV)에서 볼 수 있습니다.
  • 업로드는 헤더의 환자정보 30개 항목을 지운 뒤 ZIP에 넣고, 제외는 ZIP에 넣지 않습니다. 영상에 찍힌 글씨는 지워지지 않으므로, 썸네일에 환자정보가 보이면 반드시 제외하세요. 원본 파일은 수정되지 않습니다.

4. 비식별화 후 저장

'업로드'로 정한 파일만 환자정보 태그 30개를 지운 뒤 ZIP 파일 하나로 저장합니다.

저장 위치 정하는 법
  1. 아래 '비식별화 후 ZIP 저장'을 누르면 저장 창이 열립니다.
  2. 저장 창에 저장될 폴더가 표시됩니다. 처음에는 '다운로드' 폴더입니다. (윈도우: 창 왼쪽 목록과 위쪽 주소 표시줄 · 맥: 파일 이름 아래 '위치' 칸)
  3. 다른 곳에 두려면 폴더를 바꾼 뒤 '저장'을 누르세요. 저장이 끝나면 아래에 파일 이름과 찾는 방법이 표시됩니다.
  • 원래 폴더 구조와 이름을 그대로 유지합니다. 저장한 파일은 다시 읽어 환자정보가 모두 지워졌는지 확인합니다.
  • 지우는 항목: 환자 이름·ID·생년월일·나이·주소, Accession Number, 기관명·주소, 의뢰·판독·시행 의사와 촬영자 이름 등 30개 (시험 측이 제공한 비식별화 도구와 같은 기준). 검사 날짜와 성별은 남습니다.
  • 포털이 ZIP 업로드를 받으면 결과 ZIP을 그대로 올리고, 폴더 업로드만 받으면 압축을 풀어 나온 폴더를 올리세요.
  • 저장한 ZIP에는 '업로드'로 정한 영상이 들어 있습니다. 업로드가 끝나면 지워 주세요.
